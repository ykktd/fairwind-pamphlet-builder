# FairWind パンフレット作成ツール

企画ごとの資料を並べ、目次とページ番号を付けたPDFを作るブラウザ用ツールです。担当者は同じURLを開き、自分のGoogleアカウントでDriveに接続します。完成PDFや企画の構成は企画共有フォルダ内の「パンフ作成用」に保存します。

## 担当者の使い方

1. 「Googleに接続」を押し、資料にアクセスできるGoogleアカウントを選ぶ。
2. 「企画共有フォルダを選ぶ」で、その企画の共有フォルダを選ぶ。ツールが「パンフ作成用」を探し、なければ作る。
3. 表紙を追加し、その後にワークシート、記事、タイムライン、プロフィールPDFなどを追加する。共通資料は「共通資料から追加」を使う。
4. Google ドキュメントの企画用コピーが作られた場合は、右側の「Google ドキュメントを開く」から編集する。PDFの再生成時に最新版を取り込む。
5. プロフィールPDFを追加したら、Wikiの `p.nn 氏名（〇〇学部m年）` 形式の一覧を右側に貼り付ける。元の `p.nn` は使わず、完成PDFのページ番号を目次に入れる。
6. 左側で資料を並べ替え、中央の「PDFを再生成」を押す。全ページを確認し、「Driveに保存」を押す。

資料全体の差し替えと、複数ページPDFのうち1ページだけの差し替えができます。差し替え後はPDFを再生成してください。表紙以外の全ページにページ番号を付け、目次は表紙の次に自動挿入します。A4縦以外の資料やプロフィール人数とPDF枚数の不一致は生成前に知らせます。

「PCのPDFを追加」も使えます。Driveの保存先を選んだ状態なら追加したPDFは「パンフ作成用」にアップロードされます。先にPCの資料を追加した場合も、保存先を選んだ時にアップロードします。

## 公開先

**[共通URL](https://ykktd.github.io/fairwind-pamphlet-builder/)で公開しています。** ソースは[公開リポジトリ](https://github.com/ykktd/fairwind-pamphlet-builder)に置き、GitHub Actionsで更新を `main` に反映するとサイトも更新されます。[ViteのGitHub Pages手順](https://vite.dev/guide/static-deploy#github-pages)に沿い、リポジトリ名がURLに入る場合もフォントを読める設定にしています。

通常のGitHub Pagesサイト自体は公開URLです。サイトにはプログラム、フォント、Google接続用の公開識別子が配信されます。パンフの資料や完成PDFはGitHubへ置かず、利用者のブラウザと、アクセス権のあるGoogle ドライブで扱います。URLを知っているだけではDriveの資料を開けません。公開リポジトリを使う場合、リポジトリ内のファイルも公開されるため、企画資料や個人情報をコミットしないでください。

個人アカウントで始めてからサークルのGitHub組織へリポジトリを移せます。移転後はPagesのURLに含まれる所有者名が変わるため、Google CloudのOAuth承認済み生成元とAPIキーの参照元を新URLに更新します。移転先の組織でリポジトリ作成権限が必要です。

具体的な手順は[導入手順.md](導入手順.md)を参照してください。公開サイトの表示とローカルPDFでの生成は確認済みです。Google Drive連携の実アカウントでの動作確認は設定完了後に行います。

## 開発

Node.js 20.19以上を使います。

```sh
npm install
npm run dev
npm test
npm run build
```

開発画面は `http://127.0.0.1:5173/` です。Googleの接続値がある場合は `.env.example` を `.env.local` または `.env.production` にコピーして設定します。`VITE_` の値は完成サイトのコードに含まれるため、秘密鍵やサービスアカウントの鍵を入れないでください。APIキーはGoogle Cloudでサイトの参照元と使用APIを制限します。

## 制約

- 入力はPDFまたはGoogle ドキュメントです。Wordファイルは担当者がPDFに書き出して追加します。
- Google ドキュメントのPDF書き出しはGoogle Drive APIの上限に従います。大きな文書はPDFとして追加してください。
- Driveへの保存前のローカル資料は、そのブラウザだけに残ります。複数人で引き継ぐ企画は最初に企画共有フォルダを選んでください。
- 同じ企画を複数人が同時に編集する運用は想定していません。担当者を1人決め、必要に応じて引き継いでください。
- 印刷用の4ページ単位への調整は通知だけです。白紙の自動挿入は行いません。

## 使用フォント

目次の日本語には [Noto Sans JP](https://github.com/notofonts/noto-cjk)、数字には [Source Sans 3](https://github.com/adobe-fonts/source-sans) を使用しています。各フォントはSIL Open Font Licenseに従います。ライセンス文は `public/fonts/licenses/` に同梱しています。PDFにはフォントを埋め込みます。
