プライバシーについて

更新日：2026年9月25日

FairWind パンフレット作成ツールで扱う資料と Google ドライブのデータについて説明します。

扱う情報と利用目的

このツールは、担当者が選んだ PDF・Google ドキュメント、企画名、資料の並び順、プロフィール目次用のテキストを使い、パンフレットの PDF を作ります。Google ドライブとの接続では、選択したファイルと、このツールで作成したファイルを読む・作成する・更新するために Google の drive.file 権限を使用します。

保存先

  • PDF の結合、目次とページ番号の生成はブラウザ内で行います。このツール独自のサーバーへ資料を送信しません。
  • 企画の構成と接続設定は、利用中のブラウザの保存領域に記録します。Drive に保存する前のローカル PDF も、そのブラウザ内に保存します。
  • 企画共有フォルダを選ぶと、その中の「パンフ作成用」フォルダに、企画の構成、アップロードした資料、共通資料のコピー、完成 PDF を保存できます。これらへのアクセスは Google ドライブの共有設定に従います。
  • Google のアクセストークンは接続中のブラウザのメモリで使い、ブラウザの保存領域や GitHub リポジトリには保存しません。

外部サービス

Google アカウントの認証、ファイルの選択、Drive への読み書きには Google のサービスを利用します。サイトの配信には GitHub Pages を利用します。各サービスによる情報の取扱いは、それぞれのポリシーに従います。

接続の解除と削除

Google アカウントのサードパーティとの接続画面から、このツールへのアクセスを取り消せます。ブラウザに保存された企画データはブラウザのサイトデータを消すことで削除できます。Drive に保存した資料と完成 PDF は、権限のある担当者が Drive で削除できます。
